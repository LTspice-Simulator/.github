# LTspice Simulator - A Circuit You Drew On This Host

## Understanding LTspice Simulator Core Components

- **Schematic** - The circuit you drew and stored for LTspice Simulator.
- **Net** - The connections LTspice will actually simulate.
- **Source** - A voltage or current you placed on purpose.
- **Probe** - The node you watch after the run.
- **File** - The schematic in the folder you already named.
- **Run** - One simulation you can still explain.
- **Note** - Why this pass differs from the last saved net.

## First Look at LTspice Simulator

LTspice Simulator is for a circuit you drew on the PC you already use. LTspice keeps that schematic in the folder you named.

It does not invent a net you did not open. You draw, you run, you look at the node you meant, you save. Extra plots you will not reread can leave the working folder.

Students and lab staff can use it in different ways, but the file should still be yours. A classmate gets the path you already keep, not a screenshot of a vanished net.

## Closing Notes for LTspice Simulator

Treat LTspice Simulator as the net you will still open next week, not as a tray of unnamed plots. Open LTspice when the schematic is the one you meant. Keep the live file obvious. Move extra plots out of the working folder. Let old runs stay quiet.

If you change chairs, take the same schematic. If you show a classmate, show them the node you probed. After that, LTspice Simulator usually needs almost no explanation.

The live net should still be the file you named. If two versions sit in the same folder, trust the one you dated later and leave the other as a copy you can still open.
